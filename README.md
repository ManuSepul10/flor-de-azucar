# 🍰 Flor de Azúcar

Sitio web desarrollado para Flor de Azúcar, un emprendimiento de elaboración y venta de budines artesanales.

El objetivo es presentar los productos, comunicar la propuesta del emprendimiento y facilitar el contacto con clientes interesados en realizar pedidos.

🌐 **Sitio web:** https://flor-de-azucar-three.vercel.app/

## 🚀 Tecnologías utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Vercel

## ✨ Características

- Catálogo de budines artesanales.
- Presentación visual de los productos.
- Diseño responsive.
- Información comercial del emprendimiento.
- Acceso directo para realizar consultas y pedidos.
- Interfaz orientada a facilitar la experiencia del usuario.

## 🍪 Productos

- Budín de Oreo.
- Budín de Pepitos.
- Budín con chips de chocolate.
- Budín de vainilla.
- Budín de limón.

## 💻 Ejecución local

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Ingresar al proyecto:

```bash
cd flor-de-azucar
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor:

```bash
npm run dev
```

## 🌐 Despliegue

El sitio se encuentra publicado mediante Vercel.

Desarrollar una presencia digital para un emprendimiento real, combinando diseño, desarrollo frontend y una experiencia de usuario enfocada en la presentación de productos y captación de clientes.
